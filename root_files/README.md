# Root File Explorer

Browse Home Assistant, attached disks, and the host system from the sidebar.

Install it by adding this repository in the app store: `https://github.com/prasad7676/ha-root-files`. It is not the File Explorer from the built-in store. That one stops at the folders Home Assistant already shares. This one can also mount an attached disk and, with Protection mode off, show the rest of the machine.

Open it from the sidebar after you install it. The steps are in the Documentation tab, and in `DOCS.md`.
